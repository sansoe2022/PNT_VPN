ချိတ်ဆက်နည်း

CONNECTION GUIDE
01

Server ရွေးချယ်ပါ

SERVER LOCATION

App ထဲက Server Location ကို နှိပ်ပြီး အသုံးပြုချင်တဲ့ Server ကို ရွေးပါ။ ပုံထဲမှာ Thailand - 18 ကို ရွေးထားပါတယ်။

Ping နည်းတဲ့ Server ကို ရွေးပြီး စမ်းသုံးနိုင်ပါတယ်။
02

Network ရွေးချယ်ပါ

NETWORK PROFILE

Network Profile မှာရှိတဲ့ Change ကို နှိပ်ပါ။ မိမိသုံးနေတဲ့ SIM သို့မဟုတ် Wi-Fi နဲ့ ကိုက်ညီတဲ့ Profile ကို ရွေးပါ။

ပုံထဲက Profile က #V2Ray · ALL SIM & WIFI ဖြစ်ပါတယ်။
03

Connect ချိတ်ဆက်ပါ

TAP TO CONNECT

Server နဲ့ Network ရွေးပြီးရင် အောက်ဘက်က ပါဝါခလုတ် ⏻ ကို နှိပ်ပါ။ VPN ခွင့်ပြုချက် တောင်းလာရင် OK / Allow ကို နှိပ်ပြီး ခဏစောင့်ပါ။

✓ Connected ဖြစ်ရင် အသုံးပြုနိုင်ပါပြီပြန်ဖြုတ်ချင်ရင် ပါဝါခလုတ်ကို ထပ်နှိပ်ပါ။

ပုံတွေကို နှိပ်ပြီး App မျက်နှာပြင်အပြည့် ကြည့်နိုင်ပါတယ်။

အချိန်နဲ့ ကြော်ငြာ

TIME & ADS

အသုံးပြုချိန် ထပ်တိုးမယ်

Connection time မှာ လက်ကျန်အချိန်ကို ကြည့်နိုင်ပါတယ်။ အချိန်တိုးဖို့ Add 12h ကို နှိပ်ပြီး App မှာ ပြထားတဲ့ အဆင့်တွေကို အဆုံးအထိ လုပ်ဆောင်ပါ။ ပြီးရင် လက်ကျန်အချိန် တိုးလာတာကို စစ်ဆေးပါ။

Remove ads နဲ့ ပိုလွယ်ကူစွာ

အခမဲ့
Remove ads

App ရဲ့ ညာဘက်အပေါ်ထောင့်က Remove ads ကို နှိပ်ပြီး ပြထားတဲ့ အဆင့်တွေကို လုပ်ဆောင်ပါ။ Remove ads လုပ်ပြီးရင် ကြော်ငြာအားလုံး ဖယ်ရှားပေးပြီး Add time ထပ်လုပ်စရာမလိုဘဲ အခမဲ့ အသုံးပြုနိုင်ပါတယ်။

ကြော်ငြာမရှိAdd time မလိုအခမဲ့အသုံးပြုနိုင်

အကူအညီ လိုနေပါသလား?

QUICK HELP
ချိတ်ဆက်လို့ မရဘူးဆိုရင်
Mobile data သို့မဟုတ် Wi-Fi အင်တာနက် ရှိမရှိ အရင်စစ်ပါ။ လက်ကျန် Connection time ရှိမရှိ စစ်ပြီး Network Profile မှန်အောင် ရွေးပါ။ မရသေးရင် Server တစ်ခု ပြောင်းရွေးပြီး ပြန်ချိတ်ပါ။
Configuration ကို ဘယ်လို Update လုပ်မလဲ?

App ရဲ့ ဘယ်ဘက်အပေါ်ထောင့်က ☰ Menu ကို ဖွင့်ပြီး Update configurations ကို နှိပ်ပါ။ Update ပြီးသွားရင် Server နဲ့ Network ကို ပြန်ရွေးပြီး ချိတ်ဆက်ပါ။
